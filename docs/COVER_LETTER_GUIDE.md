# Cover letter guide

What the cover-letter settings are based on: a summary of university career-center advice, in our own words.

## Shape

- **One page at most**, three or four short paragraphs. For an email or a form's message box, three to five lines.
- **Opening:** the exact role (and job ID if there is one) and one line on why you're a fit.
- **Middle:** one or two concrete examples that match the posting's main requirements: what you did and the result.
  It should **add to the resume, not repeat it**: why this company, what you'd bring, a project that's relevant.
- **Closing:** that you'd be glad to talk, and how to reach you.
- **Address a person** if the posting names one; otherwise “Dear Hiring Team” or “Dear Hiring Manager” rather than
  “Dear Sir/Madam”.

## Tailoring

- Each letter is written for one opportunity: name the company and something specific about it (product, team,
  mission) that you actually care about.
- Use the posting's words where they're true for you, as in the resume.
- AI can help with structure, but the letter should sound like you and use your real examples. The agent's cover
  note uses placeholders (`{role}`, `{top_skills}`) and never invents facts.

## In this project

- `cover_note` (Applying tab) is the short version used as an email body and in optional message boxes.
- `cover_letter_file` (setup wizard) is attached where a form has a cover-letter upload.
- `cover_note_in_forms` switches both off for optional fields.
